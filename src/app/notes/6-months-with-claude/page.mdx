# 6 Months with Claude

#ai #claude

Six months of running Claude Code on my own Windows machine. This is what I actually kept, ordered by how much it was worth rather than by what kind of thing it is.

> Needs review.

## Essential

Rating: <Stars n={5} />

| What | Type | Notes |
| --- | --- | --- |
| `prism-docs` | Skill | All the docs, plus past conversations distilled into it. Saved me 100 hours. |
| `ask-gemini` + `agy-handoff` | Skill | Saves tons of tokens, especially when dealing with images and video. |
| The 5 hour window | Cron | A job on my remote server keeps a usage block running around the clock. |

The usage limit runs in 5 hour blocks, and a block starts from the first message, not from the moment I hit a limit. By the time I sit down the window has usually been open for a while, so it resets sooner.

## Usage

Rating: <Stars n={4} />

| What | Type | Notes |
| --- | --- | --- |
| Commit hook (ponytail + update documentation) | Hook | Claude sometimes overdoes things, and won't update the docs on its own. |
| `clip` | Skill | Useful to copy out a command, table, or a useful sentence. |
| `screen-capture` | Skill | Lets Claude see my screen and verify itself. It usually invokes this one on its own. |
| `video-summarize` | Skill | Clips videos and builds highlights from my trips. I hope it gets better in future. |
| `organize-album` | Skill | Sorts images by date across multiple sources. Very helpful. |
| Statusline | Config | Shows context usage and how much of the 5 hour limit is left. Knowing the limit helps me plan token usage ahead. |
| `opus` / `son` + one line | Profile | Fair. It gets more useful when things get token heavy. |

## Optional

| What | Type | Notes |

| Attention pipeline (Windows alert + ntfy) | Hook | I don't have to sit there and keep things going. Sometimes buggy. |

| `cc` (`claude "commit"`) | Profile | Just a shorthand. Convenient, but not necessary. |

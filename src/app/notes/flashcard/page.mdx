# AWS Cert Flashcards

#nextjs #typescript #pwa #aws #cloudflare

I was studying for the AWS Certified Solutions Architect Associate exam and reading through the question set was slow going. So I built a quick flashcard web app to study on my commute and go back over the questions I got wrong.

It has since turned into my general study app. I added JLPT past papers when I started on Japanese, then Jyutping and kana decks.
Deployed at [donchong2000.github.io/flashcard](https://donchong2000.github.io/flashcard).

## Features

### Practice Modes

- **Practice sets**: work through one topic in order
- **All questions**: cycle through the full bank
- **Random exam**: 65 shuffled questions, like the real AWS exam
- **Custom quiz**: pick tags, a question range, a status (unseen, incorrect, bookmarked...) and an optional sample size. Custom quizzes are always shuffled.

The stats cards on the home page (correct, incorrect, unseen, bookmarked) are clickable and start a quiz with that filter.

![[custom-quiz.png]]

### Progress Tracking

Answers are stored in `localStorage`, so correct/incorrect history persists across sessions. If I misclick or think the answer key is wrong, I can mark the question as correct anyway.

### Sync Across Devices

Progress syncs through a small **Cloudflare Worker** with KV storage. Each browser gets a sync ID; I share it with a link (`?sync=...`) or type it in with "Enter Sync ID". The typed version exists because an iOS home-screen app has its own storage separate from Safari, so links never reach it. Sync runs automatically when the home page opens, and there is a manual Sync button too.

### Activity Heatmap

The green streak button on the home page opens an activity page with a heatmap of answers per day and the current streak. Each device keeps its own daily counts, and sync merges them by taking the higher count per device and day, so the merge gives the same result whatever order devices sync in.

![[activity.png]]

### Keyboard Navigation

| Key | Action |
|-----|--------|
| `1`–`6` | Select option |
| `Enter` / `Space` | Submit answer, or go to the next question |
| `→` | Next question |
| `B` | Bookmark question |
| `O` / `'` | Mark a wrong answer as correct |

### Data Portability

Progress can be exported as JSON and imported again, which makes backups easy. Answer history is stored as a **hex bitmap** (one bit per question), so the file stays small. The export also carries the activity history, and import always merges it.

Sync, Export, Import and Reset live in the home page's "More" menu to keep the header clean.

### Offline / PWA

The app is installable and works fully offline, so I can study without a connection.

## Adding Question Banks

A new deck is a JSON file in the `data/` directory with a `questions` array (question, options, correct answers, and optionally tags, community votes, discussion, images or audio). The build splits it by topic and adds it to the deck list automatically.
